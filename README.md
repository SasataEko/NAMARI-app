# 化ける言語 — 発音と字形の研究用プロトタイプ

Vite と HTML/CSS/JavaScript で作ったブラウザーゲームです。日本語話者・中国語話者のプロフィールは別々に保存されますが、チャレンジ内容は共通です。

## 起動

```bash
npm install
npm run dev
```

表示されたローカル URL を開きます。公開用ファイルは `npm run build` で `dist/` に生成されます。

## 画面

- ホーム：「チャレンジする！」から「母音＆子音篇」「アクセント篇」「モーラ篇」を選びます。図鑑、DIYモード、設定は小さな円形ボタンから開きます。
- チャレンジ：篇を選んだあと、問題一覧が開きます。既存の見本に加えて、このブラウザーの DIY で作成した同じ篇の問題が自動で並び、一覧からそのままプレイできます。
- 母音＆子音篇：既存の「くすり」字形変形チャレンジを配置しています。
- アクセント篇：録音を聴き、`カリキュラム` の各拍を高/低で組み立てて提出するテンプレートです。文字を中央の第3行に並べ、高低選択点と線の高さが各拍の中心に揃います。録音と正解データは未登録のため、提出パターンを保存し「回答を記録しました」と表示します。正誤判定はまだ行いません。
- モーラ篇：サンプル語「カリキュラム」の各拍にある灰色の丸をタップして一拍を選択/解除します。長押しすると半拍または隣の拍とつなぐ長音を選べます。
- 図鑑：音声・発音特徴カードをカテゴリ別に閲覧できます。
- DIYモード：最初に母音＆子音篇、アクセント篇、モーラ篇を選びます。篇の選択カードは共通の中性灰色です。
  - 母音＆子音篇：単語と読みを入力すると自動分拍します。全ての拍に通常 SVG を登録し、正解にする拍を1つ以上選んで各々の変形後 SVG を登録できます。録音と一緒に保存すると、チャレンジ一覧から各拍をクリックして試せます。正解拍は本物の SVG path 変形、その他の拍は誤答の震え表示です。図鑑カードは任意のラベルです。
  - アクセント篇：読みを直接入力すると拍を自動分割します。拍ごとに高低を指定して録音と一緒に保存し、チャレンジ一覧から回答/判定できます。
  - モーラ篇：読みを自動分割し、拍ごとに高低、隣接する拍の長音リンク、拍の後に追加する空白拍を設定できます。保存した問題はチャレンジで回答できます。
  - 問題、音声、SVG Blob は IndexedDB に保存され、サーバーには送信されません。作成した問題は保存した同じブラウザー内で共有されます。別端末や研究参加者にも配布するには、今後サーバー共有機能または書き出し/読み込み機能が必要です。読みの自動分拍では小書き仮名を直前の仮名にまとめ、促音・撥音・長音符をそれぞれ一拍として扱います。最大16拍です。

母音＆子音篇の各 SVG は `.svg` ファイルを選択します。SVG ルートに同じ `viewBox` を指定し、各拍の通常/変形ペアごとに同じ個数・順番の閉じた `<path d="...">` を用意してください。ファイル選択時にペアを検証し、viewBox/輪郭数/Flubber 補間器のエラーは画面と開発者コンソールに出ます。現在の importer は path の `d` と `fill` を使います。グループ変換、path transform、stroke、mask、clipPath、filter、外部参照、複雑な複合パス/孔の fill-rule は保証しません。Illustrator から SVG を書き出す前に文字をアウトライン化し、余分なアンカーと構造差を減らしてください。
- 設定：効果音と振動の切り替え。

プロフィール、アクセント提出記録、設定は現在のブラウザーの `localStorage` に保存され、別端末とは同期されません。

色とタイポグラフィはルートの `DESIGN.md` の Warm Editorial Flat 仕様を参照します。ページ背景は `#FBF9F2`。チャレンジ篇は母音＆子音 `#E73A59`（白文字）、アクセント `#FFE08B`（黒文字）、モーラ `#70D7B1`（黒文字）です。DIY篇の選択カードは `#E4E2DC`。ホームのDIY円形は `#A78BFA`。この試作用の章色とDIY色は DESIGN.md に追加していません。

## 「くすり」SVG と音声

`public/assets/` に `ku-normal.svg` / `ku-accented.svg` / `su-normal.svg` / `ri-normal.svg` と `kusuri-audio.mp3` があります。SVG の素材パスは `src/data/levels.js` で管理しています。

「く」の通常/変形 SVG は同じ viewBox・座標系にし、アウトライン化した path の数と順序を揃えてください。不要なアンカーポイントを減らし、輪郭の位置と大きさも合わせます。孔を含む複合パスや、輪郭数・構造の差は形崩れや補間失敗の原因になります。現在の読み込み処理は path の `d` と fill を扱い、CSS、stroke、mask、clipPath、filter、外部参照には対応しません。失敗時は画面に説明を出し、コンソールに `[glyph-morph]` の詳細を記録します。フェード表示に切り替えることはありません。

## アクセント素材の追加

録音と正解データを受け取ったら、`src/main.js` のアクセント画面に音源を設定し、拍ごとの正解パターンをデータとして追加します。現在は5拍 (`カ・リ・キュ・ラ・ム`) を個別に選択でき、すべて選択すると「このアクセントで判定する」で回答を保存します。録音/正解情報が揃うまでは、この画面は回答記録テンプレートとして動作します。

## 主なファイル

- `src/main.js`：画面表示、遷移、回答記録、イベント処理
- `src/data/levels.js`：DIY字形と音声素材の設定
- `src/data/catalog.js`：図鑑カード
- `src/data/profileStore.js`：プロフィール、設定のローカル保存
- `src/data/diyStore.js`：DIY問題と録音 Blob を IndexedDB に保存
- `src/glyph/loadGlyph.js`：SVG 読み込み
- `src/glyph/morph.js`：Flubber による path 補間アニメーション
- `src/style.css`：テーマ、レスポンシブ UI、アニメーション
